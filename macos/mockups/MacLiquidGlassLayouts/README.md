# MacLiquidGlassLayouts (research mockup)

Quick **macOS 26+/27** SwiftUI app: park screenshot surface + **real** Liquid Glass overlays.

```bash
cd macos/mockups/MacLiquidGlassLayouts
swift run
```

Or: `../../scripts/run-mac-glass-layouts.sh`

- SF Symbols only (no invented art)
- `.glass` / `.glassProminent` / `.glassEffect` / `GlassEffectContainer` only — no fake materials
- Four corner layouts (C-direction); switch in the segmented control
