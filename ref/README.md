# Local RollerCoaster Tycoon data

Place data from a legitimate copy of RollerCoaster Tycoon 2 or RCT Classic under this directory for local testing. The preferred layout is `ref/rct2/Data/g1.dat`; the developer scripts also recognize the existing `ref/Rollercoaster Tycoon 2/Data/g1.dat` layout.

Except for this file, everything under `ref/` is ignored. Proprietary game data must never be committed, pushed, copied into an app bundle, archived, or distributed. The production iPad app requires each user to import their own data through the Files interface.
